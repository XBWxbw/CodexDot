# 光照学习图片目录

本目录用于保存后续实验截图和说明图。目前没有实验截图，也没有已完成实验的图像证据。

## 建议命名

按章节、实验步骤和变量命名，例如：

- `01-material-spheres-baseline.png`
- `01-material-spheres-base-color.png`
- `01-material-spheres-camera-angle.png`
- `01-material-spheres-exposure.png`

这些只是文件名示例，对应图片尚未生成。

## 图片说明应记录什么

- 对应章节与实验步骤
- UE 版本、渲染路径、GI 与反射方案
- 材质参数和曝光设置
- 与基准画面相比改变了什么
- 实际观察到的现象

引用图片时使用相对路径，并提供描述图片内容的替代文字。截图应避免包含账号信息、个人文件路径或其他无关私人信息。外部示意图应注明来源，并确认有权保存和使用。
