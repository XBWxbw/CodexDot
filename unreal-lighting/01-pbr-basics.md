# 第 1 章 光照基础与 PBR

第 1 部分的核心，是理解：一个像素为什么会呈现现在的颜色，以及哪些变化来自光、哪些来自材质、哪些来自相机和显示。

下面先以 UE 常见的不透明表面、传统 Default Lit 金属度工作流为例。透明、皮肤、毛发等特殊材质后面再展开。

## 1. 从“一束光到一个像素”开始

可以把过程分成四步：
- 光源发出光，光可能直接到达物体，也可能经过其他物体反弹后到达
- 材质根据光的入射方向、观察方向和自身属性，把一部分光反射出去
- 相机接收到朝向自己的那部分光
- 经过曝光、色调映射和显示编码，变成屏幕上的颜色

因此，Base Color 不是最终像素颜色。同一块白墙，在太阳下、阴影里、红墙旁边，最后的颜色都会不同。

PBR，也就是基于物理的渲染，主要要求光和材质遵循合理的物理规律，让材质在不同照明条件下仍然保持一致的性质。它不意味着计算完全精确；实时渲染会大量使用近似。

## 2. 先分清两组经常混淆的概念

直接光／间接光，描述光的路径：
- 直接光：光源的光直接到达当前表面
- 间接光：光先经过其他表面反射等过程，再到达当前表面

漫反射／镜面反射，描述当前表面对光的响应：
- 漫反射：光向较宽的方向散开，理想漫反射的出射辐亮度不随观察方向改变
- 镜面反射：光更集中在与反射方向有关的区域，观察角度对结果影响明显

这两组分类可以组合：
- 直接漫反射：太阳把白墙照亮
- 直接镜面反射：灯在塑料球上形成的亮斑
- 间接漫反射：红墙反弹的光，把旁边白墙染红
- 间接镜面反射：金属球上映出周围的房间

特别注意：粗糙金属上的模糊反射，仍然属于镜面反射。镜面反射并不只指清晰的镜子。

这也是为什么引擎里“灯光高光”和“环境反射”可能由不同流程计算，但在物理上都属于表面的镜面响应。

## 3. 渲染方程究竟在算什么

先记住它的意思，不急着背公式：

朝相机发出的光，等于表面自身发出的光，加上所有入射方向经过材质反射后、朝相机贡献的光。

每个入射方向的贡献，主要取决于：
- 那个方向来了多少光
- 材质会把多少光分配到观察方向
- 光线与表面的夹角

最后一项对应余弦因素：光线垂直照射时，相同光束集中在较小面积上；斜着照时，摊到更大面积，每单位表面收到的能量减少。

这里有两个值得认识的量：
- 辐亮度 Radiance：保留方向信息，可以理解为沿某个方向传播的光有多强
- 辐照度 Irradiance：单位表面面积从各个方向总共接收到多少光功率

它们不是同一个量，也不能直接等同于 UE 灯光面板上的 Intensity 数值。点光源的平方反比衰减，描述的是它对表面照明随距离的变化；不能简单说所有沿光线传播的辐亮度都会随距离平方下降。[PBRT：辐射度量基础](https://pbr-book.org/4ed/Radiometry,_Spectra,_and_Color/Radiometry)

对后续学习最重要的连接是：Lightmass、Lumen 等方案，主要帮助求出“周围各方向有什么光到达这里”；材质的 BRDF 决定这些光如何反射到相机方向。

## 4. BRDF：材质如何分配反射光

BRDF 可以理解为一个规则：给定入射方向和观察方向，材质会怎样把入射光分配到观察方向。

它不是简单的“反射百分比”，因为方向也参与计算。

常见 PBR 表面响应由漫反射和镜面反射两部分构成。

漫反射的入门模型是 Lambert。它用表面的漫反射颜色控制反射量，并遵循前面说的入射余弦关系。真实材质、具体引擎可能采用更复杂的模型。

镜面反射通常用微表面模型理解：看起来平整的表面，微观上由许多方向不同的小面组成。每个小面像一面微小镜子，整体效果取决于这些小面的分布。

其中常说的 D、F、G 分别负责：
- D：微表面朝向如何分布，影响高光的形状和宽度
- F：菲涅耳效应，决定不同角度下的反射比例
- G：微表面之间互相遮挡的影响

这里的 G 是材质微观结构的遮蔽，不是场景里的 Shadow Map，也不是墙角的 AO。[Epic：UE4 的 PBR 技术基础](https://cdn2.unrealengine.com/Resources/files/2013SiggraphPresentationsNotes-26915738.pdf)

## 5. 菲涅耳：为什么斜看更容易看到反光

观察玻璃、水面或光滑塑料：正着看时反射可能不强，贴着表面斜看时反射明显增强。这就是菲涅耳效应。

F0 指正入射时的反射率。许多常见非金属的 F0 在几个百分点左右，4% 是常用的默认值，但不是所有非金属都严格等于 4%。

要注意两点：
- “4%”是正入射条件下的值，不是说任意角度都只反射 4%
- 金属的镜面反射往往带颜色，例如铜和金；常见非金属表面反射通常近似无色

## 6. UE 材质参数分别控制什么

### Base Color：基础颜色
- 非金属：主要控制漫反射颜色，例如红塑料的红色
- 金属：主要控制镜面反射颜色，例如铜的偏红反射
- 尽量不要把固定灯光高光、投影和强烈明暗烘进普通 Base Color，否则换光照后容易出现重复照明

### Metallic：金属度
- 干净的非金属通常用 0
- 裸露金属通常用 1
- 中间值可用于混合、过渡或过滤后的覆盖，不是“半金属更自然”的通用调节钮
- 金属上覆盖油漆时，最外层油漆通常按非金属处理；露出底材的位置才表现为金属

在这种常用模型中，理想金属基本没有通常的体漫反射分量。因此把一个物体改成金属后，如果场景缺少合适的反射来源，它可能明显变暗，并不是金属度自动让它更亮。

### Roughness：粗糙度
- 低：反射更锐利，高光更集中
- 高：反射更模糊，高光更宽散
- 它改变反射的分布，不是简单给反射乘一个亮度系数
- Roughness 为 1 不代表没有镜面反射

### Specular：非金属镜面反射参数
- 在传统 Default Lit 工作流中，默认 0.5 对应正入射反射率约 4%，不是反射 50%
- 通常先保留默认值，有材质依据再修改
- 它不能替代 Roughness；金属端的反射颜色主要由 Base Color 决定

### Normal：着色法线
- 改变局部参与光照计算的朝向，进而改变明暗和高光
- 普通法线贴图不会自动改变物体轮廓，也不等于真实几何起伏

### Emissive：自发光
- 给表面增加自身发出的光，可以使用大于 1 的 HDR 值
- 自己看起来很亮、出现 Bloom，与真正照亮旁边物体，是不同的事情
- 能否、如何影响周围环境，取决于所用的光照方案

以上参数对应关系可对照 [UE 材质输入官方说明](https://dev.epicgames.com/documentation/en-us/unreal-engine/material-inputs-in-unreal-engine)。

## 7. 能量守恒：为什么不能把各种反射随便相加

对不主动发光的材质，反射和透射出去的总能量不能超过收到的能量，其余会被吸收。

因此，漫反射与镜面反射不能各自按“完整的一份入射光”计算后直接相加，否则可能凭空增加能量。

但能量守恒不是说：
- 每个像素都必须小于 1
- 改粗糙度后，每个角度看到的亮度都不变
- 所有材质反射的总能量都一样

高光可以很亮，只是集中在较小的方向范围；另一些方向就比较暗。材质还可能吸收光。不同实时近似也会带来能量损失或补偿误差。

## 8. 线性空间：为什么贴图颜色不能直接拿来算光照

光能量的相加、相乘，应在线性空间中进行。但常见颜色图片通常使用 sRGB 编码，文件里的数值不是线性的光强。

例如，sRGB 数值 0.5 解码后，线性值大约是 0.214，并不是 0.5。

典型处理顺序是：
- 读取颜色贴图，并从 sRGB 解码到线性空间
- 在线性空间计算材质与光照
- 经过曝光、色调映射等处理
- 编码成显示设备需要的输出

UE 中常见的原则：
- Base Color 等颜色贴图：通常使用 sRGB 解码
- Roughness、Metallic、AO 等数据贴图：通常关闭 sRGB
- Normal：按法线数据处理，不当作普通颜色图

如果一张纹理把 AO、Roughness、Metallic 分别打包到 RGB 通道，它仍然是数据贴图。

sRGB 设置错误，会改变实际输入的粗糙度或金属度数值，进而改变整个反射表现。不能把这个开关当成随手调亮调暗的工具。

## 9. HDR、曝光、Tonemapping 是三个不同概念

HDR：场景计算可以保留很大的亮度范围。线性值大于 1 是正常的，不表示计算出错。

曝光 Exposure：相当于相机对场景光的成像亮度尺度。曝光提高，画面整体会更亮；它没有改变灯光实际向场景发出多少能量。

色调映射 Tonemapping：把场景中很宽的亮度范围映射到显示输出可表达的范围，同时影响高光压缩和最终观感。

所以，“灯强翻倍”不一定表现为“屏幕数值翻倍”：
- 自动曝光可能把变化抵消
- 色调映射可能压缩高亮部分
- 最后还有显示编码

做光照实验时，优先固定曝光和后处理。否则你可能以为自己在观察材质差异，实际看到的是相机响应。[Epic：色彩与 Filmic Tonemapper](https://dev.epicgames.com/documentation/unreal-engine/color-grading-and-the-filmic-tonemapper-in-unreal-engine)

## 10. 用一个例子把这些串起来

场景里有一盏白灯、一面红墙、一个白色塑料球和一个金属球。

白色塑料球：
- 白灯照到它，产生直接漫反射
- 表面出现白灯的高光，属于直接镜面反射
- 红墙反弹的光把球的部分区域染红，属于间接漫反射
- 球上还可能出现模糊的环境反射，属于间接镜面反射

金属球：
- 在上述标准模型中，主要通过镜面反射表现照明与环境
- 粗糙度低，房间倒影清晰
- 粗糙度高，倒影被打散，但仍然是镜面反射机制
- 金属自身的 Base Color 会给反射着色

两者最终再经过同一套曝光和色调映射显示出来。

## 11. 建议做的第一个实验

搭一个简单场景，固定相机、曝光、灯光和环境反射条件，放两排相同的球：
- 第一排 Metallic 为 0，第二排为 1
- 每排 Roughness 依次设为 0.1、0.3、0.5、0.7、0.9
- 初始使用相同的中性 Base Color，Specular 保持默认

按顺序观察：
- 只改粗糙度：高光宽度、峰值和环境清晰度怎么变？
- 只改 Base Color：非金属和金属分别改变了什么？
- 移动相机：哪些颜色基本稳定，哪些反射明显移动？
- 只改曝光：画面亮了，但材质性质是否改变？

这一章真正需要掌握的，是能把画面拆成“入射光、材质响应、观察方向、成像处理”四层。后面学习 Lightmass、Lumen、反射和 AO，就能明确每项技术在改哪一层。

补充边界：UE 的 Substrate 使用更模块化的 BSDF 表达，不能把上面的传统材质接口直接当成它的全部接口；但这些光照基础仍然适用。
