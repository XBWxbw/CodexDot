# 练习 01 金属与非金属材质球

**状态：建议实验，尚未执行。** 本文将[第 1 章](../01-pbr-basics.md)的实验整理为操作与记录清单；没有实测截图、观测结果或 GPU 性能数据。

## 学习目标

通过控制变量，将画面变化拆分为入射光、材质响应、观察方向和成像处理四层，比较 Metallic、Roughness、Base Color 与曝光分别影响什么。

## 场景与适用范围

采用第 1 章的常见不透明表面、传统 Default Lit 金属度工作流。准备简单房间、白灯和可供反射的环境；可加入红墙，供后续观察间接光使用。先固定相机、曝光、后处理、灯光及环境反射条件。

请在执行时记录 UE 版本、渲染路径、GI 与反射方案。具体设置名称和功能支持可能随版本变化，本练习不预设某一版本的菜单位置。

## 材质球布置

放置两排几何形状和尺寸相同的球：

| 排列 | Metallic | 从左到右的 Roughness |
| --- | --- | --- |
| 第一排，非金属 | 0 | 0.1、0.3、0.5、0.7、0.9 |
| 第二排，金属 | 1 | 0.1、0.3、0.5、0.7、0.9 |

初始使用相同的中性 Base Color，Specular 保持默认。避免加入不同的法线贴图或自发光，导致比较时额外改变变量。

## 实验顺序

### 1. 建立基准

- 固定相机、曝光、灯光与环境反射条件。
- 保存基准画面，记录材质参数和渲染设置。
- 确认两排球除 Metallic 和对应的 Roughness 外使用一致条件。

### 2. 只比较粗糙度

依次观察同一排的五个球：

- 高光宽度如何变化？
- 高光峰值如何变化？
- 环境反射的清晰度如何变化？
- 高粗糙度的金属是否仍能表现镜面反射？

### 3. 只改 Base Color

保持其他参数不变，分别改变非金属球和金属球的 Base Color。

- 非金属上主要改变了什么？
- 金属上主要改变了什么？
- 把观察到的现象与漫反射颜色、镜面反射颜色联系起来。

### 4. 只移动相机

恢复基准材质，保持灯光与曝光不变，移动观察位置。

- 哪些颜色基本稳定？
- 哪些反射或高光明显移动？
- 斜看表面时，反射如何变化？

### 5. 只改曝光

恢复基准相机与材质，保持灯光不变，只改变曝光。

- 画面亮度如何变化？
- 材质参数是否改变？
- 能否区分光照变化与成像处理变化？

## 自检问题

- 为什么粗糙金属的模糊反射仍属于镜面反射？
- 为什么 Metallic 变为 1 后，物体不一定更亮？
- 为什么 Specular 默认 0.5 不表示反射 50%？
- 为什么曝光变亮不等于灯光发出了更多能量？
- 能否用入射光、材质响应、观察方向和成像处理解释每次变化？
